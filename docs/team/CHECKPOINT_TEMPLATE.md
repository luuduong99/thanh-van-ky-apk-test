# [TEAM-ID/TASK-ID] Handoff — mẫu dùng mỗi khi kết thúc công việc

- **Ngày / thread:** `YYYY-MM-DD` · `[TVK-0X]`
- **Branch & commit chính xác:** `branch` · `commitSHA` (chưa commit thì ghi rõ)
- **Mục tiêu:** một kết quả có thể kiểm chứng
- **File thực sự thay đổi:** tên file và lý do
- **Hợp đồng liên quan:** class/API/event/state/asset và thread phụ thuộc
- **Bằng chứng:** test count PASS/FAIL/SKIP, CI URL, screenshot/gif đúng nguồn, build artifact nếu có
- **Bằng chứng giới hạn:** không có ảnh gốc art? không chạy máy thật? không có rig? ghi thật
- **Trạng thái:** `DRAFT / READY_FOR_PR / BLOCKED / APPROVED_BY_USER` (chỉ ghi APPROVED nếu người dùng xác nhận thật)
- **Tương thích CANON / SHA:** nếu đụng asset thì ghi SHA, crop, pose, `production_release.status`
- **PR về `map-2d-prototype`:** URL và người cần review (chưa tạo thì ghi `NOT_CREATED`)
- **Việc nhỏ tiếp theo:** cụ thể, hạn chế lặp mask/tool, nêu rủi ro

**Đừng dùng câu “đã hoàn thành” nếu chỉ có mock UI, code chưa merge, CI chưa chạy, hoặc art chưa được duyệt.**
